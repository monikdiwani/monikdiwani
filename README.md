## Featured Projects

### [Nexa — Personal Daily Super App](https://github.com/monikdiwani/Nexa)
> Native Android · Java · Firebase · Material3 · WorkManager

A comprehensive Android super app — finance tracker, expense splitter, task manager, notes, and reminders in one app. Built in native Java targeting Android 7.0–16 (SDK 36).

- **Double-Column Cashbook** — Cash & Bank tracking with category filters and running balance
- **Fair Share** — Group expense splitting with a greedy debt-simplification algorithm; PDF export
- **Smart Tasks** — Priority-driven (High/Medium/Low) checklist manager
- **Custom Analytics** — Canvas-rendered bar charts with no external libraries
- **Exact Reminders** — AlarmManager + WorkManager with SDK 36-safe fallbacks

`Java` `Firebase Auth` `Firestore` `WorkManager` `AlarmManager` `Material3` `ViewPager2`
