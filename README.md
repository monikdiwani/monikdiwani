## Featured Projects

### [Nexa — Personal Daily Super App](https://github.com/monikdiwani/Nexa)
> Native Android · Java · Firebase Firestore · Material3 · WorkManager

A comprehensive Android super app designed as a unified personal productivity hub. Built entirely in native Java targeting Android 7.0 through Android 16 (SDK 36).

**Key Highlights:**
- **Double-Column Cashbook** — Tracks Cash & Bank transactions separately with category filters and running balance computation
- **Fair Share** — Collaborative group expense splitting using a **greedy debt-simplification algorithm** to minimize settlement transactions; exports PDF reports
- **Smart Tasks** — Priority-driven (High/Medium/Low) task manager with interactive checklists
- **Staggered Notes Grid** — Modern, auto-saving notes with Material3 card design
- **Scheduled Notifications** — AlarmManager-based exact reminders with SDK 36-safe fallbacks; morning and night digest summaries via WorkManager
- **Custom Analytics** — Canvas-rendered bar charts (no external libraries) for 7-day and 30-day spending trends
- **Dark Mode** — Persistent, launch-safe global dark mode toggle

`Java` `Firebase Auth` `Firestore` `WorkManager` `AlarmManager` `Material3` `ConstraintLayout` `ViewPager2`
